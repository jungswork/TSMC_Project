# TSMC Project：潔淨室／空調設計之廠址環境分析

## 目的

期末專案題目是潔淨室與空調（HVAC）設計。本 repo 負責其中的「現場環境」部分：把候選廠址的外氣品質、氣候、地質、周邊微振動來源、供水等條件，整理成後續設備選型與結構設計可以直接引用的輸入。

分析邏輯是從 `ref/` 的兩份講義反推：講義中凡是以外氣條件當輸入的公式或選型表（例如潔淨度計算的外氣粒子濃度、MAU 焓濕圖的設計乾濕球、冷卻水塔的設計濕球），其數值都取決於廠址，因此對應的現場資料就是本 repo 要蒐集與分析的對象。

候選廠址三處，先用同一套指標做橫向比較，正式地點確定後再深入：

- 高雄楠梓產業園區
- 南科台南園區
- 中科台中園區

## 目錄

| 目錄 | 內容 |
|---|---|
| `ref/` | 課程講義（PDF）與抽出的純文字版（`*.txt`，逐頁以 `--- pN ---` 分隔）。整個目錄不進版控。 |
| `notebooks/` | 資料下載與指標計算的 Jupyter Notebook，依主題編號（空品、氣候、地質／微振／水／法規）。 |
| `data/raw/` | 從公開平台下載的原始資料。不進版控，只保留 `.gitkeep`。 |
| `data/processed/` | 整理後的中間結果與指標表，供報告引用。 |
| `src/site_analysis/` | Notebook 共用的下載、清理與統計函式。 |
| `report/` | 分析報告（Markdown）：因子 → 對設計的影響 → 三地比較 → 給設計組的輸入。 |

## 環境

使用 uv 管理，Python 3.13。

```powershell
uv sync
```

需要的套件以 `uv add <套件>` 加入，會記錄在 `pyproject.toml`。
